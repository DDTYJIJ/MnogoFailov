Многофайловый C++-проект и модульное тестирование

Назначение проекта
Консольное приложение на C++ разделённое на модули (объявления в заголовочных файлах .hpp реализация в .cpp точка входа в SuperMain.cpp) с подключённым проектом модульного тестирования Microsoft Unit Testing Framework for C++

Структура репозитория
MnogoFailov Это основной проект приложения (SuperMain.cpp, Factor.hpp, Factor.cpp)
UnitTest проект модульных тестов UnitTest.cpp
План.docx план тестирования и соответствие сценариев тестам
MnogoFailov.sln файл решения Visual Studio
.gitignore правила исключения временных и сборочных файлов

Требования к запуску
ОС Windows 10/11 и NVIDIA RTX PRO 6000 Blackwell Workstation Edition OEM(Это шутка)
Microsoft Visual Studio 2022
Платформа сборки: x64 конфигурация: Debug

Инструкция по сборке и запуску тестов
1 Клонируйте репозиторий или скачайте архив с исходным кодом
2 Откройте файл решения MnogoFailov.sln в Visual Studio
3 На верхней панели выберите конфигурацию Debug и платформу x64
4 Соберите решение: в верхнем меню выберите Сборка Собрать решение (Ctrl + Shift + B)
5 Для запуска основного приложения нажмите Ctrl + F5
6 Для запуска модульных тестов откройте Тест Обозреватель тестов (Test Explorer) и нажмите Запустить все тесты в представлении

Результаты тестирования
